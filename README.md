GWRAS (General Weather Radar Analysis System) is a cross-platform severe weather post-event review and analysis software system (C/S architecture) based on radar base data. 
The software is compatible with X, C, and S band single/dual polarization radars as well as phased array radars. The system allows for 2D and 3D interactive analysis by overlaying maps, terrain, and radar products. 
When connected to the "Tianqing" cloud platform, it meets the needs of operational personnel for rapid analysis and diagnosis of historical (or real-time) radar base data and surface observation data related to severe weather events.
